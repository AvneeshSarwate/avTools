# Livecode tldraw client

This app is the React/tldraw client for the local Deno livecode runtime in
`apps/deno-notebooks/livecode`.

Start with [`../../docs/livecode/README.md`](../../docs/livecode/README.md).
That is the canonical documentation entrypoint and gives a required reading
order for architecture, current behavior, protocols, tests, known risks, design
principles, and historical material.

For a short client-local file map, see [`architecture.md`](architecture.md).
