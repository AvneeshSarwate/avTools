# Livecode Deno server

This directory contains the local HTTP/WebSocket server, analyzer, generated
runtime, project shadow workspace, and piano-roll store used by
`apps/livecode-tldraw`.

Start with [`../../../docs/livecode/README.md`](../../../docs/livecode/README.md).
That is the canonical documentation entrypoint and gives a required reading
order for architecture, current behavior, protocols, tests, known risks, design
principles, and historical material.

For a short server-local file map, see [`architecture.md`](architecture.md).
