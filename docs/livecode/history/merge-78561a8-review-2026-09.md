# Review of merge 78561a8

Reviewed on 2026-09-07 against first parent `19c7b1a`, with cleanup applied on
`3228220`. Later example simplifications were retained. Scope: the browser host
extraction, same-tab sync/actions, canvas surfaces, bake boot, and timing
galleries. Criteria: the current architecture docs and de-slop checklist.

## Architecture assessment

The main boundaries are sound: `LivecodeEngine` remains the execution owner;
the browser host owns browser resources and transports; the UI imports that
host from the same bundle graph as user modules. The new canvas view uses the
existing view codec and keeps frames out of tldraw document state. Keep those
boundaries. Splitting the host into generic services would add concepts without
removing an ownership problem.

## Fixed in this pass

- **Premature readiness:** the first `engine` status preceded construction, so
  a subscriber could receive `{}` as its initial snapshot. A real-browser
  regression reproduced this before the fix. Readiness now follows host setup;
  the uninitialized-engine cast and duplicate lock-state variable are gone.
- **Incomplete shutdown:** the new public shutdown method left its Web Lock
  pending forever and retained MIDI/audio gesture listeners. Shutdown now
  retires listeners, closes transports, and releases the lock after engine
  cleanup. Repeated shutdown and takeover outside the blocked state are inert.
- **Stale same-tab observation:** takeover closed lifecycle status while
  retaining the former engine's entity maps. Terminal engine loss now resets
  subscribed types to empty; losing only the uplink retains local truth.
  Same-tab changes also respect the subscription's type set.
- **Competing stage ownership:** the host starts before React mounts, and the
  canvas helper can create a fallback stage. React also creating the stage
  allowed two elements with the same ID. The client HTML now owns it before
  scripts execute.
- **Duplicated request handling:** broadcast and uplink replies use one op
  execution/error path, preserving connection ownership checks. Shutdown drops
  late broadcast replies instead of posting to a closed channel.
- **Misleading verification:** gallery writes now use the actual provider
  action, and pause/resume checks inspect source pixels instead of counting
  copies of a potentially frozen canvas. Unexpected fetch errors are no longer
  filtered out of the page-error assertion. Browser typechecking now includes
  both host entrypoints; bundling alone does not check them.

Removed repeated architecture essays, unsupported CSS-escape fallbacks, unused
internal exports, and redundant casts. Failed baked-file reads now produce a
diagnostic; only a 404 means there is no bake. Host import/start failures both
reach the UI's failure state with their original cause.
